\section{Introduction}\label{introduction}

In this report, I explore the \texttt{mpg}-dataset included in the
\textbf{ggplot2} package.\\
The dataset contains information about various car models, engine size,
fuel economy, and vehicle classes.

I will visualize some key relationships in the data and have chosen to
include code snippets to use as a reference for future visualizations.

\subsection{Scatter plot}\label{scatter-plot}

Shows the relationship between engine size and highway fuel consumption.

\begin{Shaded}
\begin{Highlighting}[]
\FunctionTok{ggplot}\NormalTok{(mpg, }\FunctionTok{aes}\NormalTok{(displ, hwy, }\AttributeTok{color =}\NormalTok{ class)) }\SpecialCharTok{+}
  \FunctionTok{geom\_point}\NormalTok{(}\AttributeTok{alpha =} \FloatTok{0.7}\NormalTok{) }\SpecialCharTok{+}
  \FunctionTok{geom\_smooth}\NormalTok{(}\AttributeTok{method =} \StringTok{"lm"}\NormalTok{,}
              \AttributeTok{se =} \ConstantTok{FALSE}\NormalTok{, }
              \AttributeTok{color =} \StringTok{"white"}\NormalTok{) }\SpecialCharTok{+}
  \FunctionTok{labs}\NormalTok{(}
    \AttributeTok{title =} \StringTok{"Motorsize vs Miles per gallon on Highway "}\NormalTok{,}
    \AttributeTok{x =} \StringTok{"Motorsize (litres)"}\NormalTok{,}
    \AttributeTok{y =} \StringTok{"Miles per gallon on Highway"}
\NormalTok{  ) }
\end{Highlighting}
\end{Shaded}
