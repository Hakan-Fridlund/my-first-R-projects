# My First R Projects

Welcome! This repository contains my very first steps into programming with R. It serves as a collection of explorative school and preschool projects, self-taught experiments, and code challenges built with R and R Markdown.

## 🚀 Key Concepts Learned
- **Data Structures:** Working with R's core data types — vectors, data frames, and lists.
- **Data Wrangling:** Cleaning, transforming, and summarizing data with the tidyverse (`dplyr`, `tidyr`).
- **Pipelines:** Chaining operations together using the pipe operator (`%>%` / `|>`) for readable, step-by-step data transformations.
- **Data Visualization:** Building plots and charts with `ggplot2`.
- **R Markdown:** Combining code, output, and narrative text into reproducible reports and documents.
- Essential version control principles using Git and GitHub.
